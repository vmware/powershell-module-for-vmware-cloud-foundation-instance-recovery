# Confirm-VCFRecoveryCoordinatorPrerequisites

## Synopsis

Checks for the presence of supporting software and modules for this module.

## Syntax

```powershell
Confirm-VCFRecoveryCoordinatorPrerequisites
```

## Description

The `Confirm-VCFRecoveryCoordinatorPrerequisites` cmdlet checks for the presence of supporting software and modules for this module.

## Examples

### Example 1

```powershell
Confirm-VCFRecoveryCoordinatorPrerequisites
```
