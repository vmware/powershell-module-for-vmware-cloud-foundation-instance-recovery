# Remove-SddcManagerVspClusterEntry

## Synopsis

Removes a stale Services Runtime cluster entry and its associated credential from the SDDC Manager database.

## Syntax

```powershell
Remove-SddcManagerVspClusterEntry -SddcManagerFqdn <String>
    -VcfUserPassword <String> -RootPassword <String>
    -ClusterType <String> [-autoConfirm] [<CommonParameters>]

Remove-SddcManagerVspClusterEntry -extractedSDDCDataFile <String>
    -VcfUserPassword <String> -RootPassword <String>
    -ClusterType <String> [-autoConfirm] [<CommonParameters>]

Remove-SddcManagerVspClusterEntry -OpsRegisteredComponentsFile <String> -ServicesRuntimeFqdn <String>
    -VcfUserPassword <String> -RootPassword <String>
    -ClusterType <String> [-autoConfirm] [<CommonParameters>]
```

## Description

The cmdlet connects to SDDC Manager via SSH as the `vcf` user, elevates to root, and finds the `vsp_cluster` entry for the requested cluster type. It shows the cluster entry and credential it will remove and prompts for confirmation unless you specify `-autoConfirm`.

## Example

During fleet failback, resolve the recovery site's SDDC Manager from the source VCFMS Services Runtime and remove the VCF Automation cluster entry.

```powershell
$cleanup = @{
    OpsRegisteredComponentsFile = '.\VCFOps-Registered-Component-Details.json'
    ServicesRuntimeFqdn = $sourceVcfmsServicesRuntimeFqdn
    VcfUserPassword = $vcfUserPassword
    RootPassword = $rootPassword
    ClusterType = 'CONSUMPTION'
}
Remove-SddcManagerVspClusterEntry @cleanup
```

## Parameters

| Parameter | Description |
| --- | --- |
| `-SddcManagerFqdn` | FQDN of the SDDC Manager appliance. This value takes precedence when supplied with `-extractedSDDCDataFile`. |
| `-extractedSDDCDataFile` | Path to the extracted SDDC data file used to discover the SDDC Manager FQDN. Mutually exclusive with `-OpsRegisteredComponentsFile`. |
| `-OpsRegisteredComponentsFile` | Path to `VCFOps-Registered-Component-Details.json`, generated by `Get-VcfOperationsRegisteredComponents`. Use with `-ServicesRuntimeFqdn` to discover the manager. Mutually exclusive with `-SddcManagerFqdn` and `-extractedSDDCDataFile`. |
| `-ServicesRuntimeFqdn` | Source VCFMS Services Runtime FQDN. The registration file must contain exactly one matching VSP entry with an associated SDDC Manager FQDN. |
| `-VcfUserPassword` | Password for the `vcf` SSH user. |
| `-RootPassword` | Password for root elevation on the SDDC Manager appliance. |
| `-ClusterType` | Type of cluster entry to remove. Valid values are `MANAGEMENT` and `CONSUMPTION`. |
| `-autoConfirm` | Skip the deletion confirmation prompt. |
